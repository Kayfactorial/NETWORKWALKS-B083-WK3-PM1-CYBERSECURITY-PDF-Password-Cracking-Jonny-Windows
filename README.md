## Project Overview

This project documents my Week 3 Ethical Hacking assignment with NetworkWalks.

The objective was to demonstrate the process of recovering the password of a protected PDF document, **My Locked PDF1**, using an online hashing service and **Jonny on Windows**.

The exercise was performed in a controlled learning environment for cybersecurity education.

## Tools Used

* Jonny on Windows
* Online PDF hashing service
* Password-cracking functionality
* Windows PC

## Methodology

The exercise followed these general steps:

1. Upload the protected PDF to the hashing website.
2. Generate/extract the hash associated with the PDF.
3. Copy the generated hash.
4. Import the hash into Jonny on Windows.
5. Run the password-cracking process.
6. Recover the correct password.
7. Use the recovered password to open the protected PDF.
